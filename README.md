# Frank Luis Cañas Bolaño's Portfolio

## Description

This is my personal portfolio as a junior developer. The website is built with HTML, CSS, and JavaScript, and showcases my projects, information about me, and a gallery of my pets. It includes a responsive design that adapts to different devices.

## Features

- **About Me**: An interactive section with a button that changes the text and shows/hides a welcome message.
- **Projects**: A grid of cards displaying my main Python projects, with links to their GitHub repositories.
- **Contact**: A form for visitors to contact me.
- **Pets Gallery**: A dedicated page for my pets with images and descriptions.
- **Responsive Design**: Uses CSS Grid and Flexbox to adapt to mobile, tablet, and desktop.
- **Interactivity**: Basic JavaScript for dynamic effects.

## Technologies Used

- **HTML5**: Website structure.
- **CSS3**: Styles, including custom CSS variables, Grid, and Flexbox.
- **JavaScript**: Basic interactivity.
- **Google Fonts**: Poppins and Roboto fonts for modern typography.

## Featured Projects

1. **Inventory System**: Product and stock management in Python.
2. **Student System**: Academic control and registration application.
3. **Grade Validator**: Logical tool for calculating and validating averages.

## How to Run

This is a static website. To view it:

1. Clone or download the repository.
2. Open `index.html` in your preferred web browser.
3. Navigate through the sections using the navigation menu.
